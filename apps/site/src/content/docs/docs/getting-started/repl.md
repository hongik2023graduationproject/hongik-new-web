title: "REPL 모드"
---

REPL(Read-Eval-Print Loop)은 대화형 쉘 환경입니다. 한 줄씩 코드를 입력하고 즉시 결과를 확인할 수 있습니다.

## REPL 시작

파일 이름 없이 인터프리터를 실행합니다:

```bash
./cmake-build-debug/HongIk
```

안내 문구와 함께 `>>>` 프롬프트가 표시됩니다:

```text
한국어 프로그래밍 언어 프로젝트 홍익
제작: ezeun, jh-lee-kor, tolelom
[VM 모드]
>>>
```

REPL도 파일 모드처럼 기본적으로 바이트코드 VM으로 실행됩니다. 트리워킹 인터프리터로 실행하려면 `HongIk --eval`로 시작하세요(이때는 `[VM 모드]` 줄이 나오지 않습니다).

## 기본 사용법

### 변수 선언과 출력

앞에서 선언한 변수는 이후 입력에서도 계속 쓸 수 있습니다:

```text
>>> 정수 x = 10
>>> 정수 y = 20
>>> 출력(x + y)
30
```

### 식의 값 바로 보기

`출력()` 없이 식만 입력해도 그 값이 표시됩니다(값이 `없음`이면 아무것도 표시하지 않습니다):

```text
>>> 100 + 200
300
>>> 배열 리스트 = [3, 1, 4, 1, 5]
>>> 정렬(리스트)
[1, 1, 3, 4, 5]
>>> 길이(리스트)
5
```

### 여러 줄 입력

`:`로 끝나는 줄(조건문, 반복문, 함수, 클래스 등)을 입력하면 들여쓰기된 줄을 더 받습니다. 이어지는 줄에서는 프롬프트 대신 공백 4칸이 표시됩니다. 블록이 끝나면 **빈 줄**을 입력해 실행합니다:

```text
>>> 정수 점수 = 85
>>> 만약 점수 >= 80 라면:
        출력("합격")

합격
```

```text
>>> 함수 팩토리얼(정수 n) -> 정수:
        만약 n <= 1 라면:
            리턴 1
        리턴 n * 팩토리얼(n - 1)

>>> 팩토리얼(5)
120
```

클래스도 같은 방식으로 정의할 수 있습니다.

### 오류 복구

오류가 나면 `Error:`로 시작하는 메시지가 표시되고, 입력 중이던 내용은 버려집니다. 그 전에 선언한 변수는 그대로 남아 있습니다:

```text
>>> 정수 x = 10 +
Error: [줄 1] 해당 토큰 타입 'NEW_LINE' 에 대한 prefix 파서 함수가 정의되어 있지 않습니다.
>>>
```

정적 타입 검사기의 경고(`type-warning[...]`)도 REPL에서 표시됩니다. REPL에서는 `--type-check=strict`를 줘도 `warn`으로 동작합니다.

## REPL 종료

`종료하기`를 입력하면 REPL이 끝납니다:

```text
>>> 종료하기
```

입력 끝(EOF)에서도 종료됩니다. Linux/macOS에서는 `Ctrl+D`, Windows에서는 `Ctrl+Z` 후 Enter를 누르세요. 파이프로 입력을 넘기는 경우(`HongIk < 입력.txt`)에도 입력이 끝나면 정상 종료하며, 마무리되지 않은 여러 줄 블록이 있으면 실행한 뒤 종료합니다.

## 사용 예제

### 빠른 계산

```text
>>> 정수 원금 = 1000000
>>> 실수 이율 = 0.05
>>> 출력(원금 * (1 + 이율))
1050000.0
```

### 모듈 가져오기

REPL에서도 `가져오기 "파일.hik"`로 다른 파일의 정의를 불러올 수 있습니다. 경로는 REPL을 실행한 디렉터리 기준입니다.

## REPL 제한사항

- **저장되지 않음**: REPL에서 작성한 코드는 저장되지 않으므로 오래 쓸 코드는 `.hik` 파일에 작성해 `./cmake-build-debug/HongIk 파일.hik`로 실행하세요.
- **블록은 빈 줄로 끝내기**: 여러 줄 블록은 빈 줄을 입력해야 실행됩니다.
