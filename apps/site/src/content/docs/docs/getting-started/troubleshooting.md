---
title: "자주 발생하는 오류"
---

hong-ik 프로그래밍 중 자주 만나는 오류와 해결 방법을 정리합니다. 아래 메시지는 실제 인터프리터(기본 VM)가 출력하는 그대로입니다.

## 오류 메시지 읽는 법

오류는 크게 세 가지 모양으로 나옵니다:

- **파스(문법) 오류**와 위치를 아는 런타임 오류: `[2행] 에러: [줄 2] …` 뒤에 문제의 줄이 한 번 더 표시됩니다.
- 그 밖의 런타임 오류: `Error: …`
- **정적 타입 검사 경고**: 실행 전에 `type-warning[TC001] [줄 1] …`처럼 출력됩니다. 기본(`--type-check=warn`)에서는 경고만 하고 실행을 계속하므로, 같은 문제로 이어서 런타임 오류가 날 수 있습니다.

## 타입 불일치 오류

### 오류 메시지

```text
type-warning[TC001] [줄 1] '정수' 타입 변수 'x'에 '문자' 값을 대입할 수 없습니다.
[1행] 에러: [줄 1] 선언에서 자료형과 값의 타입이 일치하지 않습니다.
  정수 x = "42"
```

### 원인

변수에 선언된 타입과 다른 타입의 값을 넣으려고 할 때 발생합니다. 자동 변환은 없으므로 `실수 y = 10`(정수를 실수 변수에)이나 `정수 x = 없음`(Optional이 아닌 변수에 없음)도 같은 오류입니다. 값이 없을 수 있는 변수는 `정수? x = 없음`처럼 선언하세요.

### 해결 방법

타입 변환 함수를 사용하세요:

```hik
// 잘못된 코드
// 정수 x = "42"

// 올바른 코드
정수 x = 정수변환("42")
출력(x)    // 42
```

연산에서도 타입을 맞춰야 합니다. `"나이: " + 25`는 `문자 + 정수: 좌항과 우항의 타입을 연산할 수 없습니다.` 오류가 납니다:

```hik
// 잘못된 코드
// 문자 결과 = "나이: " + 25

// 올바른 코드
문자 결과 = "나이: " + 문자변환(25)
출력(결과)    // 나이: 25
```

## 정의되지 않은 변수 오류

### 오류 메시지

```text
type-warning[TC006] [줄 1] 식별자 '이름'를 찾을 수 없습니다.
Error: '이름' 존재하지 않는 식별자입니다.
```

### 원인

선언하지 않은 변수를 사용하거나, 변수 이름에 오타가 있을 때 발생합니다. 현재 VM에서 지원하지 않는 `매핑`·`걸러내기`·`줄이기`·`부모`를 쓸 때도 같은 오류가 납니다([바이트코드 VM](/docs/language-reference/vm/) 참고).

### 해결 방법

1. 변수를 먼저 선언하세요:

```hik
// 잘못된 코드
// 출력(이름)    // '이름'이 정의되지 않음

// 올바른 코드
문자 이름 = "홍길동"
출력(이름)
```

2. 오타가 없는지 확인하세요:

```hik
정수 점수 = 85
// 출력(점수수)   // 오타! '점수수' → '점수'
출력(점수)        // 85
```

3. 변수의 스코프를 확인하세요. 블록 내부에서 선언한 변수는 블록 바깥에서 접근할 수 없습니다.

## 인덱스 범위 초과 오류

### 오류 메시지

```text
Error: 배열의 범위 밖 인덱스입니다: 인덱스 5, 배열 크기 3
```

### 원인

배열의 유효한 범위를 벗어난 인덱스로 접근할 때 발생합니다.

### 해결 방법

인덱스가 배열 길이 내에 있는지 확인하세요:

```hik
배열 목록 = [10, 20, 30]

// 잘못된 코드
// 출력(목록[5])    // 인덱스 범위 초과

// 올바른 코드 - 길이 확인 후 접근
만약 길이(목록) > 2 라면:
    출력(목록[2])    // 30
```

:::tip
배열의 유효한 인덱스 범위는 `0`부터 `길이(배열) - 1`까지입니다. 음수 인덱스는 `-1`(마지막)부터 `-길이(배열)`(첫 번째)까지 유효합니다.
:::

## 0으로 나누기 오류

### 오류 메시지

```text
[1행] 에러: [줄 1] 0으로 나눌 수 없습니다.
  출력(10 / 0)
```

### 원인

나눗셈이나 나머지 연산에서 오른쪽 피연산자가 0일 때 발생합니다.

### 해결 방법

나누기 전에 0인지 확인하거나, `시도`/`실패`로 처리하세요:

```hik
// 방법 1: 사전 검사
함수 안전나눗셈(정수 a, 정수 b) -> 정수:
    만약 b == 0 라면:
        출력("0으로 나눌 수 없습니다")
        리턴 0
    리턴 a / b

출력(안전나눗셈(10, 0))

// 방법 2: 예외 처리
시도:
    정수 결과 = 10 / 0
실패 오류:
    출력("오류: {오류}")
```

## 무한 루프 (타임아웃)

### 오류 메시지

웹 플레이그라운드와 문서의 실행 예제에는 실행 제한이 있어서, 반복이 100만 번을 넘거나 실행 시간이 제한을 넘으면 멈추고 다음 중 하나를 표시합니다:

```text
루프 반복 횟수 초과: 1000000
실행 시간 제한을 초과했습니다.
```

CLI(`HongIk`)에는 이런 제한이 없어 무한 루프가 끝나지 않습니다. `Ctrl+C`로 중단하세요.

### 원인

반복문의 종료 조건이 충족되지 않아 무한히 반복될 때 발생합니다.

### 해결 방법

반복문의 종료 조건과 변수 갱신을 확인하세요:

```hik
// 잘못된 코드 - i가 갱신되지 않음
// 정수 i = 0
// 반복 i < 10 동안:
//     출력(i)
//     // i += 1 을 빠뜨림!

// 올바른 코드
정수 i = 0
반복 i < 10 동안:
    출력(i)
    i += 1       // 반드시 갱신!
```

:::caution[체크리스트]
무한 루프를 방지하려면:
- `반복 ... 동안:` 에서 조건 변수가 반드시 갱신되는지 확인
- 종료 조건이 도달 가능한지 확인
- 필요하면 `중단` 키워드를 사용하여 반복을 탈출
:::

## 모듈/가져오기 오류

### 오류 메시지

```text
Error: 파일을 열 수 없습니다: utils.hik
```

### 원인

`가져오기` 문에서 지정한 파일이 없거나 경로가 잘못되었을 때 발생합니다. 웹 플레이그라운드에서는 가져올 파일이 없으므로 항상 이 오류가 납니다.

### 해결 방법

1. 확장자를 포함한 파일 이름 전체를 적으세요. `가져오기 "utils"`는 `utils.hik`를 찾지 않습니다:

```text
// 파일 구조:
// project/
//   main.hik
//   utils.hik

// main.hik에서:
가져오기 "utils.hik"
```

2. 경로는 `main.hik`의 위치가 아니라 **인터프리터를 실행한 디렉터리** 기준입니다. 위 구조라면 `project/` 폴더에서 `HongIk main.hik`로 실행하세요.
3. `..`이 들어간 경로와 절대 경로는 보안상 쓸 수 없습니다.

## 문법 오류

### 오류 메시지

```text
[2행] 에러: [줄 2] 예상하지 못한 토큰입니다. 현재 토큰: 'NEW_LINE', 예상 토큰: 'COLON'
  만약 x > 5 라면
```

### 원인

hong-ik 문법에 맞지 않는 코드를 작성했을 때 발생합니다.

### 일반적인 실수와 해결

**콜론 누락** (`예상 토큰: 'COLON'`):
```hik
// 잘못된 코드
// 만약 x > 5 라면
//     출력(x)

// 올바른 코드 - 콜론(:) 필요
만약 true 라면:
    출력("참")
```

**들여쓰기 오류** (`예상 토큰: 'START_BLOCK'`):
```hik
// 잘못된 코드 - 들여쓰기가 없음
// 만약 true 라면:
// 출력("참")

// 올바른 코드 - 블록 내부는 들여쓰기
만약 true 라면:
    출력("참")
```

**괄호 불일치** (`예상 토큰: 'RPAREN'`):
```hik
// 잘못된 코드
// 출력("안녕"

// 올바른 코드
출력("안녕")
```

**키워드를 변수 이름으로 사용:**

`계속`, `중단`, `반복`, `생성`처럼 키워드인 단어는 변수 이름으로 쓸 수 없습니다. `정수 계속 = 1`은 `해당 토큰 타입 '정수' 에 대한 prefix 파서 함수가 정의되어 있지 않습니다.` 같은 알아보기 어려운 오류를 냅니다. 다른 이름(예: `계속하기`)을 쓰세요.

**여러 줄에 걸친 배열·사전 리터럴:**

`[`나 `{` 뒤에서 줄을 바꾸면 `해당 토큰 타입 'NEW_LINE' 에 대한 prefix 파서 함수가 정의되어 있지 않습니다.` 오류가 납니다. 리터럴은 한 줄에 쓰세요.

**문자열 안의 중괄호:**

문자열 안의 `{...}`는 보간 식으로 해석됩니다. JSON처럼 중괄호를 글자로 쓰려면 `\{ \}` 또는 `{{ }}`로 이스케이프하세요. 그렇지 않으면 `문자열 보간 … 안의 식을 해석할 수 없습니다` 파스 오류가 납니다.

## 기타 런타임 오류

| 메시지 | 원인 |
|--------|------|
| `함수가 필요한 인자 개수와 입력된 인자 개수가 다릅니다.` | 함수 호출 시 인자 개수가 정의와 다름 |
| `문자열 'abc'을(를) 정수로 변환할 수 없습니다.` | `정수변환`에 숫자가 아닌 문자열을 넘김 (웹에서는 `입력`이 빈 문자열을 반환하므로 `정수변환(입력(...))`도 이 오류) |
| `사전에 키가 존재하지 않습니다.` | 없는 키로 사전에 접근함 — `포함(사전, 키)`로 먼저 확인 |
| `정수 연산 결과가 범위를 넘었습니다.` | 정수 계산 결과가 64비트 범위를 넘음 |
| `조건식의 결과는 논리(참/거짓) 값이어야 합니다.` | `만약`/`반복 … 동안`의 조건이 논리 값이 아님 |
| `메서드 호출은 인스턴스에서만 사용할 수 있습니다.` | 클래스 인스턴스가 아닌 값에 메서드를 호출함 |

## 디버깅 팁

1. **`출력()`으로 중간 값을 확인하세요** - 가장 간단한 디버깅 방법입니다
2. **`타입()`으로 변수의 타입을 확인하세요** - 타입 관련 오류에 유용합니다
3. **코드를 작은 단위로 나눠서 테스트하세요** - 문제의 범위를 좁힐 수 있습니다
4. **REPL 모드를 활용하세요** - 한 줄씩 실행하며 결과를 확인할 수 있습니다

```hik
// 디버깅 예시
정수 값 = 42
출력("값: " + 문자변환(값))         // 값: 42
출력("타입: " + 타입(값))           // 타입: 정수
```
