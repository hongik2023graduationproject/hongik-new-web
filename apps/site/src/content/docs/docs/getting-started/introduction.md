**hong-ik**은 한글을 기반으로 설계된 자체 프로그래밍 언어 프로젝트입니다.

## 특징

- **한글 문법**: 한국어 키워드로 직관적이고 읽기 쉬운 코드 작성
- **바이트코드 VM**: C++로 구현된 바이트코드 VM이 기본 실행 엔진이고, CLI에서는 트리워킹 인터프리터(`--eval`)로도 실행 가능
- **OOP 지원**: 클래스, 상속, 메서드 오버라이딩 등 객체 지향 프로그래밍 지원
- **풍부한 내장 함수**: 45개의 내장 함수 + 고차 함수 3종(`매핑`·`걸러내기`·`줄이기`, 현재 `--eval` 전용)
- **안전한 예외 처리**: `시도`/`실패`(try/catch)를 통한 구조화된 에러 처리
- **정적 타입 검사**: 실행 전에 타입 오류를 찾아 알려 주는 검사기(`--type-check`)
- **모듈 시스템**: `가져오기`로 파일 단위의 코드 조직 및 재사용 (CLI)
- **웹 플레이그라운드**: 설치 없이 [브라우저에서 바로 실행](/playground/)

## 누가 사용할 수 있나?

- **프로그래밍 입문자**: 한글로 작성된 자연스러운 문법으로 학습
- **한국 개발자**: 친숙한 언어로 알고리즘 개발 및 스크립트 작성
- **언어 연구자**: 프로그래밍 언어 구현 및 인터프리터 개발 학습

## 코드 예제

```hik
함수 인사(문자 이름) -> 문자:
    리턴 "안녕하세요, " + 이름 + "님!"

출력(인사("홍길동"))  // 안녕하세요, 홍길동님!
```

더 많은 예제는 [튜토리얼](/docs/tutorials/basics-variables/)을 참고하세요.
