이 튜토리얼에서는 함수를 인자로 전달하여 배열을 변환하는 방법을 배웁니다.

:::caution[현재 `--eval` 전용]
내장 고차 함수 `매핑`, `걸러내기`, `줄이기`는 현재 CLI의 트리워킹 인터프리터(`HongIk --eval 파일.hik`)에서만 동작합니다. 웹 플레이그라운드와 이 페이지의 실행 예제는 기본 VM으로 실행되므로 이 함수들을 쓰면 `존재하지 않는 식별자` 오류가 납니다. 그래서 아래의 내장 고차 함수 예제는 실행 버튼 없이 코드로만 보여 주고, 웹에서 바로 실행해 볼 수 있는 `각각` 반복문 버전을 함께 제공합니다.
:::

## 매핑 - 배열 변환

배열의 각 요소에 함수를 적용합니다:

```hik
함수 두배(정수 x) -> 정수:
    리턴 x * 2

배열 원본 = [1, 2, 3, 4, 5]
배열 결과 = 매핑(원본, 두배)
출력(결과)    // [2, 4, 6, 8, 10]
```

## 걸러내기 - 조건 필터

조건에 맞는 요소만 선택합니다:

```hik
함수 짝수(정수 x) -> 논리:
    리턴 x % 2 == 0

배열 숫자 = [1, 2, 3, 4, 5, 6, 7, 8]
배열 짝수들 = 걸러내기(숫자, 짝수)
출력(짝수들)    // [2, 4, 6, 8]
```

## 줄이기 - 값 축약

배열을 하나의 값으로 합칩니다:

```hik
함수 합(정수 a, 정수 b) -> 정수:
    리턴 a + b

정수 총합 = 줄이기([1, 2, 3, 4, 5], 합, 0)
출력(총합)    // 15
```

## 조합하기

고차 함수를 연결하면 강력한 데이터 처리가 가능합니다:

```hik
함수 양수(정수 x) -> 논리:
    리턴 x > 0

함수 제곱(정수 x) -> 정수:
    리턴 x * x

함수 합(정수 a, 정수 b) -> 정수:
    리턴 a + b

배열 데이터 = [-3, -1, 0, 2, 5]

// 양수만 골라서 제곱하고 합산
배열 양수들 = 걸러내기(데이터, 양수)      // [2, 5]
배열 제곱들 = 매핑(양수들, 제곱)           // [4, 25]
정수 결과 = 줄이기(제곱들, 합, 0)         // 29

출력(결과)    // 29
```

## 웹에서 실행해 보기: `각각`으로 직접 만들기

같은 일을 `각각` 반복문으로 하면 VM(웹 플레이그라운드)에서도 실행됩니다. 함수는 `함수` 타입 매개변수로 넘길 수 있으므로, 매핑·걸러내기를 직접 만들 수도 있습니다:

<InlinePlayground client:visible>

```hik
함수 내매핑(배열 목록, 함수 변환) -> 배열:
    배열 결과 = []
    각각 정수 x 목록 에서:
        추가(결과, 변환(x))
    리턴 결과

함수 내걸러내기(배열 목록, 함수 조건) -> 배열:
    배열 결과 = []
    각각 정수 x 목록 에서:
        만약 조건(x) 라면:
            추가(결과, x)
    리턴 결과

함수 양수(정수 x) -> 논리:
    리턴 x > 0

함수 제곱(정수 x) -> 정수:
    리턴 x * x

배열 데이터 = [-3, -1, 0, 2, 5]
배열 제곱들 = 내매핑(내걸러내기(데이터, 양수), 제곱)
출력(제곱들)    // [4, 25]

정수 합계 = 0
각각 정수 x 제곱들 에서:
    합계 = 합계 + x
출력(합계)    // 29
```

</InlinePlayground>

## 실전 예제: 단어 분석

```hik
함수 긴단어(문자 단어) -> 논리:
    리턴 길이(단어) >= 3

배열 단어들 = 분리("안녕 나는 프로그래머 입니다", " ")
배열 긴것들 = 걸러내기(단어들, 긴단어)
출력(긴것들)    // [프로그래머, 입니다]
```

`각각` 반복문 버전 (웹에서도 실행됨):

```hik
배열 단어들 = 분리("안녕 나는 프로그래머 입니다", " ")
배열 긴것들 = []
각각 문자 단어 단어들 에서:
    만약 길이(단어) >= 3 라면:
        추가(긴것들, 단어)
출력(긴것들)    // [프로그래머, 입니다]
```
