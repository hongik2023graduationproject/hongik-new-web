---
title: "클래스 정의"
---

`클래스` 키워드를 사용하여 객체를 정의합니다.

## 기본 구문

```text
클래스 이름:
    // 필드
    타입 필드명

    // 생성자
    생성(매개변수):
        자기.필드 = 값

    // 메서드
    함수 메서드명() -> 반환타입:
        // 본문
```

## 예제

```hik
클래스 동물:
    문자 이름
    정수 나이

    생성(문자 이름, 정수 나이):
        자기.이름 = 이름
        자기.나이 = 나이

    함수 소개() -> 문자:
        리턴 "저는 {자기.이름}, {자기.나이}살입니다."
```

## 인스턴스 생성, 필드 접근, 메서드 호출

클래스 이름을 함수처럼 호출하여 인스턴스를 생성하고, 점(`.`) 연산자로 필드를 읽거나 메서드를 호출합니다:

```hik
클래스 동물:
    문자 이름
    정수 나이

    생성(문자 이름, 정수 나이):
        자기.이름 = 이름
        자기.나이 = 나이

    함수 소개() -> 문자:
        리턴 "저는 {자기.이름}, {자기.나이}살입니다."

동물 강아지 = 동물("뽀삐", 3)    // 인스턴스 생성
출력(강아지.이름)                // 뽀삐
출력(강아지.나이)                // 3
출력(강아지.소개())              // 저는 뽀삐, 3살입니다.
```

:::note[현재 제약]
- 필드에 값을 대입하는 것은 클래스 안에서 `자기.필드 = 값` 형태로만 할 수 있습니다. 바깥에서 `강아지.나이 = 4`처럼 대입하면 파스 오류가 나므로 값을 바꾸는 메서드를 만드세요.
- `자기.값 += 1` 같은 복합 대입은 필드에 쓸 수 없습니다. `자기.값 = 자기.값 + 1`로 쓰세요.
:::

## 자기 키워드

`자기`는 현재 인스턴스를 참조합니다. 다른 언어의 `this`/`self`에 해당합니다:

```hik
클래스 카운터:
    정수 값

    생성():
        자기.값 = 0

    함수 증가():
        자기.값 = 자기.값 + 1

    함수 현재값() -> 정수:
        리턴 자기.값

카운터 c = 카운터()
c.증가()
c.증가()
출력(c.현재값())    // 2
```
