title: "타입 시스템 개요"

hong-ik에서는 변수를 선언할 때 타입을 적고, 모든 값은 명확한 타입을 가집니다.

## 지원 타입

| 타입 | 키워드 | 설명 | 예제 |
|------|--------|------|------|
| 정수 | `정수` | 부호가 있는 64비트 정수 | `정수 x = 42` |
| 실수 | `실수` | 64비트 부동소수점 | `실수 pi = 3.14` |
| 문자 | `문자` | 유니코드 문자열 | `문자 s = "안녕"` |
| 논리 | `논리` | 참/거짓 | `논리 flag = true` |
| 배열 | `배열` | 동적 크기 배열 | `배열 arr = [1, 2, 3]` |
| 사전 | `사전` | 키-값 쌍 | `사전 map = {"a": 1}` |
| 튜플 | `튜플` | 바꿀 수 없는 값 묶음 | `튜플 t = (1, 2)` |
| 함수 | `함수` | 함수 값 (매개변수·반환 타입으로 사용) | `함수 적용(함수 f, 정수 x)` |
| 없음 | `없음` | 값이 없음을 나타내는 값 | `정수? x = 없음` |

클래스를 정의하면 클래스 이름도 타입으로 쓸 수 있습니다(`동물 a = 동물("뽀삐", 3)`).

## 기본 타입 상세

### 정수 (Integer)

```hik
정수 x = 10
정수 음수 = -5
정수 큰수 = 1000000000
```

범위: -2^63 ~ 2^63-1. 계산 결과가 범위를 넘으면 런타임 오류가 납니다([정수](/docs/language-reference/integer/) 참고).

### 실수 (Float)

```hik
실수 pi = 3.14
실수 음수 = -2.5
```

64비트 IEEE 754 부동소수점입니다. `1.23e-4` 같은 지수 표기는 지원하지 않습니다.

### 문자 (String)

```hik
문자 greeting = "안녕하세요"
문자 empty = ""
문자 escaped = "줄바꿈: \n탭: \t"
```

**문자열 보간:**
```hik
문자 name = "홍길동"
문자 message = "안녕 {name}님"
출력(message)    // 안녕 홍길동님
```

### 논리 (Boolean)

```hik
논리 참값 = true
논리 거짓값 = false
```

### 배열 (Array)

```hik
배열 빈배열 = []
배열 숫자배열 = [1, 2, 3]
배열 혼합배열 = [1, "문자", true]

정수 개수 = 길이(숫자배열)
정수 첫원소 = 숫자배열[0]
정수 마지막 = 숫자배열[-1]
출력(개수)      // 3
출력(첫원소)    // 1
출력(마지막)    // 3
```

### 사전 (Dictionary)

```hik
사전 빈사전 = {}
사전 정보 = {"이름": "홍길동", "나이": 25}
문자 이름 = 정보["이름"]
출력(이름)    // 홍길동
```

## Optional (`타입?`)과 없음

일반 타입의 변수에는 `없음`을 넣을 수 없습니다. `정수 x = 없음`은 `선언에서 자료형과 값의 타입이 일치하지 않습니다.` 오류입니다. 값이 없을 수도 있는 변수는 타입 뒤에 `?`를 붙여 Optional로 선언합니다:

```hik
정수? 없는값 = 없음
출력(없는값 == 없음)    // true

없는값 = 7
만약 없는값 != 없음 라면:
    출력(없는값 + 1)    // 8
```

함수의 반환 타입도 `-> 정수?`처럼 Optional로 쓸 수 있습니다.

## 타입 검사

- **선언 시 검사**: 선언한 타입과 값의 타입이 다르면 실행 중 `선언에서 자료형과 값의 타입이 일치하지 않습니다.` 오류가 납니다.
- **자동 변환 없음**: 정수를 실수 변수에 넣는 것도 오류입니다(`실수 y = 10`). 필요하면 `실수변환()` 같은 함수로 명시적으로 변환합니다. 단, 산술 연산에서 정수와 실수를 섞으면 결과는 실수가 됩니다(`10 + 2.5` → `12.5`).
- **정적 타입 검사기**: 실행 전에 코드를 훑어 타입 오류를 찾습니다. CLI 옵션 `--type-check=off|warn|strict`로 조절하며 기본값은 `warn`입니다. `warn`은 `type-warning[...]` 경고를 출력하고 그대로 실행하고, `strict`는 `type-error[...]`를 출력하고 실행하지 않습니다. 예를 들어 `정수` 변수에 나중에 문자열을 다시 대입하는 코드는 정적 검사기만 잡아냅니다.

## 타입 변환

암묵적인 타입 변환은 없습니다. 변환 함수를 사용하세요:

```hik
문자 str = "42"
정수 num = 정수변환(str)
출력(num)     // 42

정수 n = 100
문자 text = 문자변환(n)
출력(text)    // 100

문자 fstr = "3.14"
실수 f = 실수변환(fstr)
출력(f)       // 3.14

정수 x = 10
실수 y = 실수변환(x)
출력(y)       // 10.0
```

## 타입 확인

`타입()` 함수는 값의 타입 이름을 문자열로 돌려줍니다:

```hik
정수 x = 10
출력(타입(x))    // 정수

문자 s = "hello"
출력(타입(s))    // 문자
```

## 값 비교

```hik
정수 a = 10
정수 b = 10
출력(a == b)    // true

문자 s1 = "abc"
문자 s2 = "abc"
출력(s1 == s2)  // true
```

## 동작 안내

### 값 vs 참조

기본 타입(정수, 실수, 문자, 논리)은 **값 타입**이고, 컬렉션(배열, 사전)은 **참조 타입**입니다:

```hik
정수 x = 10
정수 y = x
y = 20
출력(x)  // 10 (x는 변경되지 않음)

배열 arr1 = [1, 2, 3]
배열 arr2 = arr1
추가(arr2, 4)
출력(길이(arr1))  // 4 (arr1도 변경됨)
```
