---
title: "고차 함수"
---

고차 함수는 다른 함수를 매개변수로 받거나 반환하는 함수입니다. hong-ik은 `매핑`, `걸러내기`, `줄이기` 내장 함수를 통해 고차 함수를 지원합니다.

:::caution[현재 `--eval` 전용]
`매핑`, `걸러내기`, `줄이기`는 현재 CLI의 트리워킹 인터프리터(`HongIk --eval 파일.hik`)에서만 동작합니다. 기본 실행 엔진인 바이트코드 VM — 웹 플레이그라운드와 문서의 실행 예제 포함 — 에서는 `'매핑' 존재하지 않는 식별자입니다.` 오류가 납니다. VM에서는 `각각` 반복문으로 같은 일을 할 수 있습니다([튜토리얼](/docs/tutorials/intermediate-higher-order/) 참고).
:::

## 함수를 인자로 전달

함수 이름을 값처럼 인자로 전달할 수 있습니다. 매개변수 타입은 `함수`로 적습니다. 이 기능은 VM(웹 포함)에서도 동작합니다:

```hik
함수 두배(정수 x) -> 정수:
    리턴 x * 2

함수 적용(함수 f, 정수 x) -> 정수:
    리턴 f(x)

출력(적용(두배, 5))    // 10
```

## 매핑 (map)

배열의 각 요소에 함수를 적용합니다:

```hik
함수 제곱(정수 x) -> 정수:
    리턴 x * x

배열 결과 = 매핑([1, 2, 3, 4], 제곱)
출력(결과)    // [1, 4, 9, 16]
```

## 걸러내기 (filter)

조건에 맞는 요소만 선택합니다:

```hik
함수 양수(정수 x) -> 논리:
    리턴 x > 0

배열 결과 = 걸러내기([1, -2, 3, -4, 5], 양수)
출력(결과)    // [1, 3, 5]
```

## 줄이기 (reduce)

배열의 요소를 하나의 값으로 축약합니다:

```hik
함수 합(정수 a, 정수 b) -> 정수:
    리턴 a + b

정수 결과 = 줄이기([1, 2, 3, 4, 5], 합, 0)
출력(결과)    // 15
```

## 조합 활용

고차 함수를 연결하여 복잡한 데이터 변환을 수행합니다:

```hik
함수 양수(정수 x) -> 논리:
    리턴 x > 0

함수 두배(정수 x) -> 정수:
    리턴 x * 2

배열 숫자 = [-3, -1, 0, 2, 5]
배열 결과 = 매핑(걸러내기(숫자, 양수), 두배)
출력(결과)    // [4, 10]
```

자세한 내용은 [내장 고차 함수](/docs/builtin-functions/higher-order/)를 참고하세요.
