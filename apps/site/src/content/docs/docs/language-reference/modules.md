---
title: "모듈 & 가져오기"
---

`가져오기` 키워드를 사용하여 다른 파일의 코드를 불러옵니다.

## 기본 구문

```text
가져오기 "파일경로.hik"
```

## 예제

### 수학 유틸리티 모듈

`수학.hik`:
```hik
함수 제곱(정수 x) -> 정수:
    리턴 x * x

함수 세제곱(정수 x) -> 정수:
    리턴 x * x * x
```

`메인.hik`:
```hik
가져오기 "수학.hik"

출력(제곱(5))      // 25
출력(세제곱(3))    // 27
```

### 클래스 모듈

`동물.hik`:
```hik
클래스 동물:
    문자 이름
    정수 나이

    생성(문자 이름, 정수 나이):
        자기.이름 = 이름
        자기.나이 = 나이

    함수 소개() -> 문자:
        리턴 자기.이름
```

`메인.hik`:
```hik
가져오기 "동물.hik"

동물 강아지 = 동물("뽀삐", 3)
출력(강아지.소개())    // 뽀삐
```

## 주의사항

- 가져온 파일의 모든 정의(함수, 클래스, 변수)가 현재 스코프에 추가됩니다.
- 경로는 가져오는 파일의 위치가 아니라 **인터프리터를 실행한 현재 작업 디렉터리** 기준입니다. 위 예제는 `메인.hik`와 같은 폴더에서 `HongIk 메인.hik`로 실행한다고 가정합니다.
- 같은 파일을 여러 번 가져오면 처음 한 번만 실행됩니다.
- 보안을 위해 `..`이 들어간 경로와 절대 경로는 쓸 수 없습니다(`파일 경로에 '..'을 사용할 수 없습니다.` 오류).
- 파일 모드와 REPL 모두에서 쓸 수 있습니다.
- 정적 타입 검사기는 아직 가져온 파일의 내용을 보지 않습니다. 그래서 실행은 정상이어도 가져온 이름마다 `type-warning[TC006] … 식별자 '제곱'를 찾을 수 없습니다.` 경고가 출력될 수 있습니다. 경고가 거슬리면 `--type-check=off`로 실행하세요.

:::note[웹에서는]
웹 플레이그라운드와 문서의 실행 예제에서는 `가져오기`를 쓸 수 없습니다. 가져올 파일을 올려 둘 곳이 없고, 같은 실행 안에서 `파일쓰기`로 만든 파일도 `가져오기`에서는 보이지 않아 `파일을 열 수 없습니다: 수학.hik` 오류가 납니다. 여러 파일로 나눈 프로그램은 CLI(`HongIk`)로 실행하세요.
:::
