---
title: "조건문 (if/else)"
---

`만약`/`라면`/`아니면` 키워드를 사용하여 조건 분기를 수행합니다.

## 기본 구문

```text
만약 조건 라면:
    // 조건이 참일 때 실행
```

조건은 반드시 논리 값(`true`/`false`)이어야 합니다. `만약 1 라면:`처럼 다른 타입을 쓰면 `조건식의 결과는 논리(참/거짓) 값이어야 합니다.` 오류가 납니다.

블록 안에서 선언한 변수는 블록 밖에서 보이지 않습니다(블록 스코프). 블록 밖에서 쓸 변수는 조건문 앞에서 미리 선언하세요.

## if-else

```hik
정수 x = 3

만약 x > 5 라면:
    출력("크다")
아니면:
    출력("작다")
```

출력:
```
작다
```

## else-if 체이닝 (`아니면 만약`)

`아니면 만약 … 라면:`으로 조건을 이어서 검사할 수 있습니다. 위에서부터 차례로 검사해 처음 참인 블록 하나만 실행하고, 모두 거짓이면 마지막 `아니면:` 블록을 실행합니다(`아니면:`은 생략 가능).

```hik
정수 점수 = 85

만약 점수 >= 90 라면:
    출력("A 학점")
아니면 만약 점수 >= 80 라면:
    출력("B 학점")
아니면 만약 점수 >= 70 라면:
    출력("C 학점")
아니면:
    출력("F 학점")
```

출력:
```
B 학점
```

## 중첩 조건문

```hik
정수 나이 = 20
논리 학생 = true

만약 나이 >= 18 라면:
    만약 학생 라면:
        출력("성인 학생")
    아니면:
        출력("성인")
아니면:
    출력("미성년자")
```

## 복합 조건

논리 연산자를 사용하여 여러 조건을 결합합니다:

```hik
정수 x = 15

만약 x > 10 && x < 20 라면:
    출력("10과 20 사이")

만약 x == 10 || x == 15 라면:
    출력("10 또는 15")
```
