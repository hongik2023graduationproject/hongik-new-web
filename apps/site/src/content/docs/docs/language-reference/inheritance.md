---
title: "상속 (Inheritance)"
---

`<` 기호를 사용하여 클래스를 상속합니다.

## 기본 구문

```text
클래스 자식클래스 < 부모클래스:
    // 추가 필드 및 메서드
```

## 예제

```hik
클래스 동물:
    문자 이름
    정수 나이

    생성(문자 이름, 정수 나이):
        자기.이름 = 이름
        자기.나이 = 나이

    함수 소개() -> 문자:
        리턴 자기.이름

클래스 강아지 < 동물:
    함수 소리() -> 문자:
        리턴 "멍멍"

강아지 뽀삐 = 강아지("뽀삐", 3)
출력(뽀삐.소개())    // 뽀삐 (부모 메서드)
출력(뽀삐.소리())    // 멍멍 (자식 메서드)
```

## 부모 메서드 사용

자식 클래스는 부모 클래스의 모든 필드와 메서드를 상속받습니다:

```hik
클래스 도형:
    문자 이름

    생성(문자 이름):
        자기.이름 = 이름

    함수 설명() -> 문자:
        리턴 "도형: " + 자기.이름

클래스 원 < 도형:
    실수 반지름

    생성(실수 반지름):
        자기.이름 = "원"
        자기.반지름 = 반지름

    함수 넓이() -> 실수:
        리턴 3.14159 * 자기.반지름 * 자기.반지름

원 c = 원(5.0)
출력(c.설명())    // 도형: 원
출력(c.넓이())    // 78.53975
```

생성자가 없는 자식 클래스는 부모의 생성자를 그대로 사용합니다(위의 `강아지("뽀삐", 3)`). 자식 클래스에 생성자를 정의하면 부모 생성자는 자동으로 호출되지 않으므로, 필요한 필드를 자식 생성자에서 직접 채웁니다(위의 `원`).

## 메서드 오버라이딩

자식 클래스에서 부모와 같은 이름의 메서드를 정의하면 자식의 메서드가 사용됩니다. 부모 타입으로 선언한 변수에 자식 인스턴스를 넣을 수도 있습니다:

```hik
클래스 동물:
    문자 이름

    생성(문자 이름):
        자기.이름 = 이름

    함수 소리() -> 문자:
        리턴 "..."

    함수 소개() -> 문자:
        리턴 자기.이름 + ": " + 자기.소리()

클래스 고양이 < 동물:
    함수 소리() -> 문자:
        리턴 "야옹"

동물 나비 = 고양이("나비")
출력(나비.소개())    // 나비: 야옹
```

## 부모 메서드 호출 (`부모`)

메서드 안에서 `부모.메서드()`로 부모 클래스의 메서드를 호출할 수 있습니다.

:::caution[현재 `--eval` 전용]
`부모.메서드()` 호출은 현재 CLI의 트리워킹 인터프리터(`HongIk --eval 파일.hik`)에서만 동작합니다. 기본 VM — 웹 플레이그라운드와 문서의 실행 예제 포함 — 에서는 `'부모' 존재하지 않는 식별자입니다.` 오류가 납니다.
:::

```hik
클래스 동물:
    문자 이름

    생성(문자 이름):
        자기.이름 = 이름

    함수 소개() -> 문자:
        리턴 "저는 " + 자기.이름

클래스 강아지 < 동물:
    함수 소개() -> 문자:
        리턴 부모.소개() + "입니다, 멍멍!"

강아지 뽀삐 = 강아지("뽀삐")
출력(뽀삐.소개())    // 저는 뽀삐입니다, 멍멍! (--eval)
```
