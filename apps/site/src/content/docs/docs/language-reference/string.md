---
title: "문자 (String)"
---

문자 타입은 텍스트 데이터를 나타냅니다.

## 선언

```hik
문자 이름 = "홍길동"
문자 빈문자 = ""
```

## 문자열 보간

문자열 안에 중괄호 `{식}`을 쓰면 그 자리에 식의 값이 들어갑니다. 변수뿐 아니라 연산, 인덱싱, 필드 접근, 함수 호출 등 **어떤 식이든** 쓸 수 있습니다:

```hik
문자 이름 = "홍길동"
배열 점수 = [90, 85]
출력("안녕 {이름}님")                 // 안녕 홍길동님
출력("첫 점수의 두 배: {점수[0] * 2}")  // 첫 점수의 두 배: 180
출력("이름 길이: {길이(이름)}")        // 이름 길이: 3
```

클래스 메서드 안에서는 `"{자기.이름}"`처럼 필드도 바로 넣을 수 있습니다. 보간 식 안에서 문자열 리터럴을 쓰려면 따옴표를 `\"`로 이스케이프합니다:

```hik
사전 학생 = {"이름": "김철수", "점수": 95}
출력("{학생[\"이름\"]}: {학생[\"점수\"] + 5}점")    // 김철수: 100점
```

### 중괄호를 글자 그대로 쓰기

중괄호 자체를 출력하려면 `{{`·`}}` 또는 `\{`·`\}`로 이스케이프합니다. 짝이 없는 `{`와 빈 `{}`는 그대로 남습니다:

```hik
출력("{{이름}}")          // {이름}
출력("\{ \"키\": 1 \}")    // { "키": 1 }
출력("빈 중괄호 {}")      // 빈 중괄호 {}
```

:::caution
이스케이프하지 않은 `{...}` 안이 올바른 식이 아니면(예: JSON 문자열 `"{\"a\": 1}"`) **파스 오류**가 납니다. 중괄호를 글자로 쓰려면 반드시 이스케이프하세요. 정의되지 않은 변수를 `{없는이름}`으로 쓰면 실행 중 오류가 납니다.
:::

## 문자열 연결

`+` 연산자로 문자열을 연결합니다:

```hik
문자 성 = "홍"
문자 이름 = "길동"
문자 전체이름 = 성 + 이름
출력(전체이름)    // 홍길동
```

## 인덱싱

문자열의 개별 문자에 접근할 수 있습니다:

```hik
문자 텍스트 = "안녕하세요"
출력(텍스트[0])     // 안
출력(텍스트[-1])    // 요 (음수 인덱싱)
출력(텍스트[1:3])   // 녕하 (슬라이싱)
```

인덱스는 바이트가 아니라 글자 단위로 셉니다. 문자열은 바꿀 수 없으므로 `텍스트[0] = "a"` 같은 대입은 할 수 없습니다.
