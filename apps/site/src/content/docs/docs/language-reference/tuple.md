---
title: "튜플 (Tuple)"
---

튜플은 변경할 수 없는(immutable) 순서가 있는 값들의 컬렉션입니다.

## 생성

괄호를 사용하여 튜플을 생성하고, `튜플` 타입으로 변수에 담습니다:

```hik
튜플 좌표 = (10, 20)
튜플 사람 = ("홍길동", 25, true)
출력(좌표)    // (10, 20)
출력(사람)    // (홍길동, 25, true)
```

## 인덱싱

배열과 같은 방식으로 요소에 접근합니다:

```hik
튜플 숫자 = (1, 2, 3)
출력(숫자[0])          // 1
출력(숫자[2])          // 3
출력((1, 2, 3)[1])     // 2
```

튜플은 바꿀 수 없으므로 `숫자[0] = 5`처럼 요소에 대입하면 `인덱스 대입이 지원되지 않는 형식입니다.` 오류가 납니다. 배열과 달리 현재 튜플은 음수 인덱스(`숫자[-1]`), `길이()`, `각각` 반복문을 지원하지 않습니다.

## 활용: 여러 값 반환

함수에서 여러 값을 한 번에 돌려줄 때 유용합니다:

```hik
함수 최소최대(정수 a, 정수 b) -> 튜플:
    리턴 (최소(a, b), 최대(a, b))

튜플 결과 = 최소최대(5, 2)
출력(결과[0])    // 2
출력(결과[1])    // 5
```
