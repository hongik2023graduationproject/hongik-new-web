---
title: "실수 (Float)"
---

실수 타입은 부동소수점 숫자를 나타냅니다.

## 선언

```hik
실수 pi = 3.14159
실수 음수 = -2.5
실수 영 = 0.0
```

실수 변수에는 반드시 소수점이 있는 값을 넣어야 합니다. `실수 x = 1`처럼 정수를 넣으면 `선언에서 자료형과 값의 타입이 일치하지 않습니다.` 오류가 납니다(자동 변환 없음). `1.0`으로 쓰거나 `실수변환(1)`을 사용하세요. `1.23e-4` 같은 지수 표기는 지원하지 않습니다.

## 연산

정수와 동일한 산술 연산을 지원합니다:

```hik
실수 a = 10.5
실수 b = 3.2

출력(a + b)    // 13.7
출력(a - b)    // 7.3
출력(a * b)    // 33.6
출력(a / b)    // 3.28125
```

## 정수와 실수의 혼합 연산

정수와 실수를 함께 연산하면 결과는 실수가 됩니다:

```hik
정수 a = 10
실수 b = 3.5
출력(a + b)    // 13.5
```

## 출력 형식

실수는 출력할 때 소수점 아래 6자리까지 반올림해 표시하고 끝의 0은 지웁니다:

```hik
출력(10.0 / 3.0)    // 3.333333
출력(2.50)          // 2.5
출력(7.0)           // 7.0
```
