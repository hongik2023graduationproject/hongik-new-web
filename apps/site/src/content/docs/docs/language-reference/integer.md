---
title: "정수 (Integer)"
---

정수 타입은 소수점 없는 숫자를 나타냅니다. 범위는 64비트 부호 있는 정수(-9223372036854775808 ~ 9223372036854775807)입니다.

## 선언

```hik
정수 x = 42
정수 음수 = -10
정수 영 = 0
```

## 연산

```hik
정수 a = 10
정수 b = 3

출력(a + b)    // 13 (덧셈)
출력(a - b)    // 7  (뺄셈)
출력(a * b)    // 30 (곱셈)
출력(a / b)    // 3  (나눗셈)
출력(a % b)    // 1  (나머지)
출력(a ** b)   // 1000 (거듭제곱)
```

정수끼리 나누면 결과도 정수이며 소수점 아래는 버립니다(0 쪽으로 버림: `-7 / 2`는 `-3`). 실수 결과가 필요하면 한쪽을 실수로 만드세요: `7 / 2.0`은 `3.5`입니다. 0으로 나누면 `0으로 나눌 수 없습니다.` 오류가 납니다.

## 증가·감소

```hik
정수 count = 1
count++
count++
count--
출력(count)    // 2
```

## 비교 연산

```hik
출력(10 == 10)    // true
출력(10 != 5)     // true
출력(10 > 5)      // true
출력(10 < 20)     // true
출력(10 >= 10)    // true
출력(10 <= 15)    // true
```

## 복합 대입

```hik
정수 x = 10
x += 5     // x = 15
x -= 3     // x = 12
x *= 2     // x = 24
x /= 4     // x = 6
출력(x)    // 6
```

## 범위 넘침 (overflow)

`+`, `-`, `*`, 단항 `-`, `++`/`--`, `+=` 같은 복합 대입의 결과가 정수 범위를 넘으면 값이 조용히 뒤집히지 않고 **런타임 오류**가 납니다.

```hik
정수 큰수 = 9223372036854775807
시도:
    정수 넘침 = 큰수 + 1
실패 오류:
    출력(오류)    // [줄 3] 정수 연산 결과가 범위를 넘었습니다.
```

거듭제곱(`**`)만은 예외입니다. 결과가 정수 범위를 넘거나 지수가 음수이면 오류 대신 **실수**로 계산합니다.

```hik
출력(2 ** 10)    // 1024
출력(2 ** 63)    // 9223372036854775808.0
출력(2 ** -1)    // 0.5
```
