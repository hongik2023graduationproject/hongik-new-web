---
title: "사전 (Dictionary)"
---

사전은 키-값 쌍의 컬렉션입니다.

## 선언

```hik
사전 정보 = {"이름": "홍길동", "나이": "25"}
사전 빈사전 = {}
```

## 값 접근

키를 사용하여 값에 접근합니다:

```hik
사전 정보 = {"이름": "홍길동", "나이": "25"}
출력(정보["이름"])    // 홍길동
출력(정보["나이"])    // 25
```

없는 키에 접근하면 `사전에 키가 존재하지 않습니다.` 런타임 오류가 납니다. 먼저 `포함(정보, "키")`로 확인하세요.

## 값 설정

대괄호 대입으로 값을 추가하거나 변경할 수 있습니다:

```hik
사전 정보 = {"이름": "홍길동", "나이": 25}
정보["나이"] = 26
정보["도시"] = "서울"
출력(정보)    // {"나이": 26, "도시": 서울, "이름": 홍길동}
```

사전을 출력하면 키는 정렬된 순서로, 키에만 따옴표가 붙어 표시됩니다.

`설정()` 내장 함수로도 값을 추가하거나 변경할 수 있습니다:

```hik
사전 정보 = {"이름": "홍길동"}
설정(정보, "나이", "25")
출력(정보["나이"])    // 25
```

## 키 목록

`키목록()` 함수로 모든 키를 배열로 가져옵니다. 키는 정렬된 순서로 나옵니다:

```hik
사전 정보 = {"이름": "홍길동", "나이": "25"}
배열 키들 = 키목록(정보)
출력(키들)    // [나이, 이름]
```

## 요소 삭제

`삭제()` 함수로 키-값 쌍을 제거합니다:

```hik
사전 정보 = {"이름": "홍길동", "나이": "25"}
삭제(정보, "나이")
출력(키목록(정보))    // [이름]
```
