---
title: "파일 I/O"
---

파일 읽기/쓰기를 위한 내장 함수입니다. 경로는 현재 작업 디렉터리 기준이며, 보안을 위해 `..`이 들어간 경로와 절대 경로는 쓸 수 없습니다.

:::note[웹에서는]
웹 플레이그라운드와 문서의 실행 예제는 브라우저 안의 **메모리 파일시스템**을 씁니다. 미리 준비된 파일은 없고, `파일쓰기`로 만든 파일은 같은 실행 안에서만 읽을 수 있으며 어디에도 저장되지 않습니다. 실제 디스크의 파일을 다루려면 CLI(`HongIk`)로 실행하세요.
:::

## 파일읽기(경로)

파일의 내용을 문자열로 읽어 반환합니다.

```hik
파일쓰기("data.txt", "첫 줄\n둘째 줄")
문자 내용 = 파일읽기("data.txt")
출력(내용)
```

출력:
```
첫 줄
둘째 줄
```

### 오류 처리

파일이 존재하지 않으면 `파일을 열 수 없습니다: <경로>` 오류가 발생합니다. `시도`/`실패`로 처리하세요:

```hik
시도:
    문자 내용 = 파일읽기("없는파일.txt")
실패 오류:
    출력("오류: {오류}")    // 오류: 파일을 열 수 없습니다: 없는파일.txt
```

## 파일쓰기(경로, 내용)

문자열을 파일에 씁니다. 파일이 존재하면 덮어씁니다.

```hik
파일쓰기("output.txt", "안녕하세요!")
출력(파일읽기("output.txt"))    // 안녕하세요!
```

### 활용 예제

```hik
// 데이터 저장
배열 이름들 = ["김철수", "이영희", "박민수"]
문자 내용 = ""

각각 문자 이름 이름들 에서:
    내용 = 내용 + 이름 + "\n"

파일쓰기("이름목록.txt", 내용)

// 데이터 읽기
문자 저장된내용 = 파일읽기("이름목록.txt")
출력(저장된내용)
```

### 파일 복사

```hik
파일쓰기("원본.txt", "복사할 내용")

시도:
    문자 원본 = 파일읽기("원본.txt")
    파일쓰기("사본.txt", 원본)
    출력("파일 복사 완료")
실패 오류:
    출력("오류: {오류}")
```
